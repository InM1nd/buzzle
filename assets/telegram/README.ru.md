# Buzzle · Telegram channel assets

28.10.2026. Три изображения для канала, на просмотр. В Telegram ничего не публиковалось.

- channel-avatar.png — 640×640: крупная Жужа на медовом фоне, без текста. Файл квадратный; круговая обрезка остаётся Telegram. Лицо, корона и усики проверены в круглом превью, включая размер 48 px.
- post-welcome.png — 1280×720: логотип Buzzle, Жужа, светлая пушистая пчела и сцена сот для закреплённого приветственного поста.
- post-playtest.png — 1280×720: логотип Buzzle, точная надпись Join the Android playtest, пчёлы держат телефон с иллюстрацией головоломки. Экран телефона — рекламная иллюстрация по актуальному скриншоту, не настоящий кадр приложения.

Все три PNG RGB, фон непрозрачный. Стиль — существующий мягкий faceted low-poly Buzzle, медовые и кремовые цвета. Референсы: assets/icon-hive.png, wordmark-01, актуальный 01-puzzle-round.png из архива владельца. Использован встроенный imagegen; после генерации только масштабирование и экспорт точных размеров.

checks.json содержит размеры, формат и вес. Исходники и точные промпты: design/art/telegram-channel-assets-v1/sources/ и generation.json. Обзор preview.png показывает оба поста и круглый аватар в нескольких размерах. Сам аватар не имеет нарисованных круглых углов.

Исходная иконка приложения, код игры и app.json не менялись. Отдельно assets/store/screenshots-captioned/01…06.png обновлены реальными кадрами из buzzle-screenshots.zip.
