# Все варианты глифов / выбор для сборки

Сводный лист all-styles.png: 7 семейств и 14 наборов. Обычные слева, Halloween справа. Выбраны 1,3,4,5,7; 2 и6 только в библиотеке.

1. Яркие (1.5) — classic / hbright.
2. Мягкий кристалл — soft / hsoft.
3. Матовая пастель — pastel / hpastel.
4. Тёплый воск — wax / hwax.
5. Медовый · мягче — balanced / hbalanced, одобренный v2.
6. Медовый · грани — faceted / hfaceted, одобренный v3.
7. Яркие · спокойнее — mellow / hmellow, обычные и Halloween.

Видимый масштаб одинаковый; бомбы показаны целиком и в одном компактном размере для сравнения материала. Это лист выбора стиля, не точная симуляция размера бомбы внутри игровой клетки. Под каждой группой дополнительно показаны шесть глифов в малом размере.

Для подключённых стилей использованы текущие WebP игры, для v4 — PNG из design/art/glyph-contrast-options-v4/normal. В первых четырёх обычных наборах тыква общая, как в текущем коде; это подписано на листе. Источники каждого элемента — manifest.json. Картинки только размещены и масштабированы, RGB не менялись. Промежуточные отвергнутые генерации не являются отдельными семействами этого листа.

Статус «подключён» относится к коду v1.6, а не к любому ранее установленному APK. Выбор владельца зафиксирован: 1,3,4,5,7. Файлы игры и настройки при сборке листа не менялись.
