# Анимация одобренной Жужи

Просмотр: http://127.0.0.1:8099/?beePreview=1&revision=7

Используется одобренный спрайт. Взмахи крыльев, моргание и лёгкое покачивание выполнены средствами приложения. Крылья и глаза выделяются SVG-масками из исходной картинки. При моргании область под глазом заполняется цветом лица. Картинка приложения и иконка не перерисованы.

В тестовом экране доступны «Пауза / Движение», крупный вид, улей и коллекция. В улье учитывается посадка: амплитуда вращения крыльев уменьшается при работе на соте. Проверка производится на тестовых данных, сохранения игрока не меняются.

Ограничения: пока один исходный ракурс и вид уровня 10; корона встроена в спрайт. Другие уровни, новые наряды и непрерывный 3D-разворот ещё не подготовлены. Анимация является 2D-анимацией слоёв, а не созданием 3D-модели.

Исправлена остановка крыльев в браузере после первого взмаха: веб-версия использует JS-драйвер повторения, native-приложение — нативный драйвер. При перезапуске общий таймер крыльев сбрасывается в начало цикла.

Проверки: TypeScript, экспорт web, четыре теста жизненного цикла анимации. В браузере после пяти секунд работы подтверждены 28 разных положений каждого крыла за 120 кадров, после паузы и продолжения — 30; на паузе движение отсутствует. Ранее выполнен экспорт Android JS/Hermes и просмотрены карточка, улей и коллекция. На настоящем Android-устройстве пока не проверено.

Добавлена совместимая с установленной версией Expo зависимость react-native-svg. После распаковки исходников нужно выполнить npm ci, затем npm run web и открыть адрес с параметром beePreview=1.
