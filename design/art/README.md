# Buzzle — арт-техники (как рисовать ассеты)

Один и тот же набор в каждой технике: маскот Жужа + Пушинка, Шмель Борис, Лаванда; 7 сот (5 цветов пыльцы, бомба, радуга);
улей, цветок, капля мёда, 4 иконки вкладок; справа — фрагмент поля 5×4 с цепочкой (реальный кусок доски из генератора игры).

Запас APK до 24 МБ ≈ 0,7 МБ; новый набор заменяет текущие 664 КБ. Ни одна техника не требует reanimated/Skia/react-native-svg:
всё рисуется кодом (SVG/PIL) при сборке и кладётся в APK как PNG/WebP.

Сборка: `cd src && python3 build.py art-1-flat …` (HTML/SVG → Chrome headless 2x), `python3 overview.py`, `python3 measure.py` (замер веса → sizes.json).
