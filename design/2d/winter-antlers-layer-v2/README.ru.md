# Оленьи рожки · три ракурса отдельными слоями

19.11.2026. Новые: передние три четверти q3-front и правый профиль side. Анфас front скопирован из winter-antlers-layer-v1 без изменений. Кандидаты на просмотр, не автоматическое утверждение.

Для каждого ракурса:
- antlers-ANGLE.png/.webp — самостоятельный аксессуар с прозрачным фоном.
- hat-fitted-ANGLE.png/.webp — тот же аксессуар на полном каноническом холсте 1366×1151.
- antennae-ANGLE.png/.webp — исходные фрагменты усиков, восстановленные в области пересечения с аксессуаром, без смещения и перерисовки.
- fitting-ANGLE.png — статическая сборка для просмотра.

preview.png — все ракурсы отдельно и на Жуже, на тёмном и светлом фоне, с миниатюрами 64/96/128 px. layout.json — координаты и порядок слоёв; checks.json — копия анфаса, сохранение пикселей вне области аксессуара и PNG/WebP на двух фонах. Анфас использует те же имена слоёв по ракурсам, что и новые виды.

Новые ракурсы сделаны встроенным imagegen по отдельному аксессуару анфас и прежним примеркам winter-wardrobe-v4. Оригиналы в sources/, точные промпты и референсы в generation.json. Два ракурса — самостоятельные рисунки; мелкие грани могут различаться. Плоского поворота анфаса нет. Тела, лица и крылья взяты из канонических исходников Жужи без изменений.

При сборке использовать одну трансформацию для канонической пчелы, hat-fitted и antennae. Начало всех готовых слоёв (0,0). Это статические ракурсы, не совмещённые кадры покадровой анимации. Старые варианты сохранены. assets/ и src/ не менялись, в игру не подключено.
