# Варианты спокойных сот Buzzle

Три листа сравнения созданы встроенным image_gen из прежнего набора глифов и бомбы. Полные промпты — в prompts.json. Это варианты для выбора оформления; листы не являются готовым атласом игровых спрайтов.

1. **Мягкий кристалл** — прежняя гранёная стилистика, мягче границы граней и блики. 01-soft-crystal.png.
2. **Матовая пастель** — меньше декоративных граней, приглушённые цвета, простой бортик. Рекомендованный спокойный вариант. 02-matte-pastel.png.
3. **Тёплый воск** — более землистая палитра: охра, пыльная роза, вересковый, серо-синий, шалфей. 03-warm-wax.png.
4. **Уютный Хеллоуин** — тыквенный янтарь, клюквенная роза, приглушённый фиолетовый, сумеречный синий и мшистый зелёный. Основные символы сохранены; на бортиках небольшие сезонные детали: тыквенный черешок, стежки, паутинка, полумесяц и осенние листочки. Бомба в маленькой ведьминской шляпке. 04-halloween.png. Генерация встроенным image_gen из варианта матовой пастели; полный промпт — halloween-prompt.txt.

После замечания владельца первый сезонный вариант отнесён к тёплому воску. Подготовлены две отдельные версии с сохранением материала и палитры соответствующей базы:

- **4А — Хеллоуин / мягкий кристалл:** 04a-halloween-soft-crystal.png. Сохраняет грани, розовый, сиреневый, голубой и мятный цвета мягкого кристалла.
- **4Б — Хеллоуин / матовая пастель:** 04b-halloween-matte-pastel.png. Сохраняет матовую поверхность, мягкие пастельные цвета и простой бортик.

Обе версии добавляют сезонные детали на бортики и ведьминскую шляпку на компактную бомбу. Основные значения глифов сохранены. Созданы встроенным image_gen; промпты и роли референсов — halloween-v2-prompts.json. Файл halloween-soft-crystal-and-matte-pastel.png сравнивает каждую базу с её сезонной версией в одном масштабе. Рабочие ассеты игры не заменялись.

current-and-all-options-halloween.png — текущие игровые изображения и все четыре альтернативы в одном масштабе. Исходные цвета сохранены; изображения только кадрированы и размещены для сравнения. Это дополнительный сезонный вариант для выбора, в игру не подключён.

compare.png — механически собранные листы рядом для просмотра, без перерисовки их пикселей.

**bomb-compact.png** — отдельный прозрачный PNG новой бомбы: мягче грани, компактнее корона, пустые поля вокруг. В текущей реализации GameScreen изображение бомбы растягивается на всю клетку. При подключении важно сохранить поля либо отдельно ограничить размер самого знака примерно 55–60% высоты клетки и вписать его с сохранением пропорций. Автоматическая обрезка прозрачных полей снова увеличит бомбу.

**Предложение настройки:** «Оформление сот: Мягкое / Насыщенное». По умолчанию мягкое; для насыщенного можно сохранить прежний набор. Переключаются подготовленные изображения сот, а символы остаются чёткими. Общая яркость всего интерфейса не меняется. Следующий шаг после выбора — отдельные прозрачные PNG/WebP выбранного комплекта и примерка на плотном игровом поле, затем подключение настройки.

Рабочие ассеты и настройки игры в этом проходе не заменялись. Читаемость показана на листах, проверка в реальном размере клеток остаётся частью подготовки выбранного комплекта.
