# Зимние грядки v2 · общий контур

Сухой PNG скопирован без изменений из winter-garden-beds-v1. Для политой грядки взята ранее нарисованная в imagegen влажная почва из v1; она перенесена только внутрь рамки сухой грядки. PNG и lossless WebP: 1536×768, одинаковый альфа-канал. Проверка в render.py подтверждает, что за пределами маски почвы пиксели одинаковы.

preview.png — сравнение. index.html — переключение с одним неподвижным растением; координата основания стебля на холсте грядки (768, 390). demo-plant.webp — копия для демонстрации. Предыдущий комплект сохранён. В игру не подключено.
