# Наушники и нимб — первая версия

13 октября 2026. Два новых прозрачных PNG и примеры посадки на Жужу для оценки владельцем. В игру не подключены.

## Файлы
headphones.png — мятные наушники с золотой окантовкой, дальняя чашка в узком профиле.
halo.png — золотой объёмный нимб.
headphones-on-zhuzha-preview.png / halo-on-zhuzha-preview.png — примеры наложения на исходную Жужу; исходник пчелы не изменён.
compare.png — аксессуары отдельно и пример на персонаже.
manifest.json — промпты первоначальной генерации и исходные пути.
revision-prompt.txt — дополнительный промпт исправления наушников.

## Инструмент
Встроенный image_gen, transparent_background=true, отдельный вызов для каждого предмета.
Референсы: утверждённая Жужа без короны и принятые коробки для палитры и граней.
Наушники дополнительно отредактированы встроенным image_gen: дальняя чашка стала узкой, чтобы не закрывать глаз.
Исходные выбранные PNG скопированы без изменения рисунка или альфы. Нимб 1536×1024 (альфа 0–254), наушники 1774×887 (альфа 0–255).
Примеры посадки составлены наложением отдельного аксессуара на исходную пчелу, без перерисовки её лица, тела или крыльев.
Скрытые настройки модели инструмент не предоставляет.

## Визуальная оценка и ограничения
Оба глаза в исправленной примерке наушников открыты. Нимб расположен выше макушки.
Это пример посадки для одного ракурса Жужи, не универсальная привязка ко всем пчёлам. Для Бориса, воротничков, цветов и других форм нужна индивидуальная сверка.
При игровом наложении нужны правильные передние/задние слои относительно усиков, головы и крыльев. Нимб не должен перекрывать усики одинаково по всей окружности; его задняя половина может потребовать отдельного слоя.
Наушники также требуют разделения ободка и чашек при перекрытии головы/крыльев. Другие ракурсы аксессуаров ещё не сделаны.
Проверить совместимость с короной и головными уборами по существующим правилам нарядов перед интеграцией.

Теперь все 35 базовых изображений из списка дорисованы, но наличие PNG не означает утверждение каждого ассета или готовое подключение в игру. Следующий шаг: отдельный общий просмотр нового комплекта и проверка посадок/масштабов в интерфейсе.
