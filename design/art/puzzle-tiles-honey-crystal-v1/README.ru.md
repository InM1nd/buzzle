# Клетки головоломки — Медовый кристалл

13 октября 2026. Шесть новых PNG-кандидатов, прежние игровые клетки не заменены.

| Файл | Цвет / символ |
|---|---|
| cell0.png | Жёлтый / солнце |
| cell1.png | Розовый / сердце |
| cell2.png | Фиолетовый / цветок |
| cell3.png | Синий / капля |
| cell4.png | Зелёный / лист |
| cell-wild.png | Радужный / звезда |

Все PNG 1254×1254, прозрачность 0–255. compare.png показывает крупные клетки, размеры 32/48/72 px и условное поле. Условное поле служит сравнением соседних цветов, это не скриншот рабочей игры.

Инструмент: встроенный image_gen, по отдельному вызову для каждого рисунка, transparent_background=true. Полные промпты и исходные пути — manifest.json. Стилевой референс: новый зелёный жетон усилителя; смысловой референс для каждого рисунка: его прежняя игровая клетка.

Сохранены цвета и символы старого набора, добавлены крупные грани, объём края и светлый рельеф знаков. На листе основные символы различимы в миниатюрах. У солнца в 32 px отдельные лучи смягчаются. Цветок сохраняет пятилистную форму; генерация оставила пятиугольное отверстие вместо круглого центра. Бортики вышли более выраженными, чем предполагал промпт; оценить их визуальную насыщенность на настоящем поле перед подключением.

Размер и фаска отдельных генераций немного различаются. Для подготовки к игровому полю потребуется унификация видимых размеров и привязки; одинаковый размер PNG сам по себе этого не гарантирует. Здесь рисунки сохранены без перерисовки. Коллаж использует только механическое кадрирование, уменьшение и размещение готовых пикселей.

В игру не подключено, утверждённые пчёлы и остальные ассеты не изменены. Комплект также сохранён в design/art/puzzle-tiles-honey-crystal-v1 рабочей ветки, на GitHub в этом шаге не загружался.

Следующие отдельные рисунки: бомба, кольцо выделения, соты — заполненная, пустая и заблокированная. После визуального утверждения нужен общий просмотр с интерфейсом.
