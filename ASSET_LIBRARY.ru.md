# Постоянный каталог графики

**Ссылка для владельца:** http://127.0.0.1:8110/buzzle-style-board/

Все новые ассеты добавлять в эту коллекцию. Старый адрес доски сохранён; сравнение стилей находится на отдельной вкладке. Локальный каталог в workspace: `../../outputs/buzzle-style-board/index.html` относительно корня этого репозитория.

Полная инструкция, области сканирования и правило для следующих художественных задач: [design/art/asset-library/README.ru.md](design/art/asset-library/README.ru.md).

Это локальный каталог, доступный при работающем сервере. Он не является публичной публикацией или релизом игры. Запускатель «Открыть коллекцию Buzzle.command» восстанавливает сервер по тому же адресу.
