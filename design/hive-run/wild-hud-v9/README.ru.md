# Игровой HUD · v9

На просмотре. Результат изучения Wild Hive и новых .agents/skills. Обоснование и источники — RESEARCH.ru.md.

## Файлы
- index.html — кликабельный макет, четыре фона; ?single=1 — телефон.
- main.png / prepared.png — до/после назначения 2/8/2, 1080×1920.
- plan.png — окно −/+ без клавиатурного контура на снимке; в самом макете контур фокуса сохранён.
- winter-evening.png — готовый вечерний зимний фон.
- overview.png — три состояния на одном листе.
- app.js / style.css — редактируемый исходник макета.
- ui/panel-source.png — заготовка панели, встроенный image_gen, прозрачный фон. ui/panel.webp — механический crop и lossless WebP. ui/generation.json — точный промпт. Это материал макета, не утверждённый production-ассет.

## Реализовано в макете
Единый HUD, группа инструментов, пространственные ярлыки назначений на сотах. Предметная кромка панелей вместо белых pill-карточек. Выбранные пользователем −/+ сохранены. Фокус и вход в назначения работают через соту и нижний инструмент. Сохранение не запускает сезон.

## Проверка
Проверены 360×640, 390×720, 430×840 и 360×600 на четырёх фонах: загрузка картинок, границы HUD/поля/инструментов, цели касания. Найденные маленькие цели сот на 600 px исправлены до ≥44 px. Проверены 4/6/2 → 2/8/2 → применение → результат, inert фона, начальный фокус, стек меню → квота → назад, возврат фокуса, замыкание Tab. Окно назначения помещается при 360×640 без скролла. Pop числа запускается и заканчивается; после завершения активных анимаций нет. Gamepad и реальные Android/Telegram-insets не проверялись; CSS safe-area поддержана на уровне макета.

## Границы
Исходные пчёлы, предметы и соты — ../assets/, фоны — ../ui-options-v5/backgrounds/. Новая генерация — только панель. Значки на сотах не вводят правила строительства. Числа условные из v4, потери не моделируются. Результат не списывает квоту и не начинает год. Смена сезона меняет оформление, не формулы. Прогресс игрока не читается и не записывается. Основная игра, src/, assets/, сохранения и сборки не менялись. Предыдущие версии сохранены.
