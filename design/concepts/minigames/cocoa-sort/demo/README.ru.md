# Какао-сорт — демо без ассетов
Открыть: /cocoa-sort/demo/. Визуализация целиком HTML/CSS, без изображений, шрифтов или внешних зависимостей.
Два фиксированных решаемых уровня: 6 кружек / 4 напитка и 8 кружек / 5 напитков. Тап по исходной, затем целевой кружке. Переливается максимальный одинаковый верхний блок в пределах свободного места, только на совпадающий цвет или в пустую кружку. Полная одноцветная кружка блокируется.
Отмена: 3 раза, включая победный ход. Дополнительная кружка: 1 раз. Добавление очищает историю отмены, чтобы отмена не удаляла добавленную кружку. Смена темы не сбрасывает игру. Рейтинг: 3 звезды до длины контрольного решения +3, 2 до +8, затем 1. Это условные пороги для пробы.
Демо отдельно от основной игры, прогресс не сохраняется; перезагрузка начинает заново. Код не импортирует ассеты и не меняет игровую экономику/сохранения.
Проверено: оба уровня пройдены через интерфейс (14 и 17 ходов); отмена, бустер, смена темы; 360 и 390 px без горизонтального скролла. Логика проверена отдельно, результаты test-results.txt.
