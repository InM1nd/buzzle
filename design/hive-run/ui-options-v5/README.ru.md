# Интерфейс забега · варианты v5

Два направления на просмотре. Структура, источники, ограничения и причины решений — DESIGN.ru.md. Все предыдущие версии сохранены.

- index.html — сравнение, переключатель лето/осень/зима день/зима вечер; обе панели кликабельны.
- a-main.png / a-plan.png — светлое направление: главный экран и три группы назначения одновременно.
- b-main.png / b-plan.png — черничное направление: главный экран и фокус на одной группе.
- Эти четыре изображения по умолчанию используют зимний вечер.
- Суффиксы -summer, -autumn, -winter-day — те же состояния на других готовых фонах.
- Все отдельные скриншоты 1080×1920. compare.png — четыре основных состояния в ряд. seasonal-compare.png — оба главных экрана на четырёх фонах.
- backgrounds/ — WebP-копии готовых артов для просмотра. Новые фоны не генерировались.
- style.css / mockups.js — отдельный дизайн-пример, без импортов из основной игры и сохранений.

Проверено: 48 сочетаний (360/390/430 ×640, 2 направления, 4 фона, 2 состояния), без переполнений, скрытых прокруткой блоков назначения, отсутствующих картинок и кнопок меньше 44×44. Пройден перенос двух пчёл с вылазки на переработку в обоих вариантах: 4/6/2 → 2/8/2, сохранение и показ условного результата 180 мёда, 0 нектара, 14 пчёл. Реальная удобность требует пользовательской проверки; баланс не утверждён.
