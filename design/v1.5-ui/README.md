# Buzzle v1.5 — макеты интерфейса (финальный набор)

Цель v1.5: разгрузить интерфейс, оставив его ярким и тёплым. Одно ядро (улей + головоломка), максимум 3 обязательных дела в день, всё вторичное спрятано, но легко находится.

> ⚠️ Это **дизайн-прототип**, а не код игры. Все **цифры условные** (мёд, прогресс, цены, награды). **Графика временная**: пчёлы, сундуки, сад и соты будут заменены новым артом, который готовит Александр.

## Структура (5 одинаковых вкладок)

| Вкладка | Что внутри |
|---|---|
| **Улей** | Переключатель **Соты / Сад**. Соты: поляна с ульем, кнопка «Собрать», карточка Жужи «Сегодня 3 дела» (по нажатию — вкладка «Задания»), свободное место под украшения. Сад: грядки, «Полить всё», место под украшения. |
| **Играть** | Головоломка дня, **головоломка выходных** (СБ–ВС, 30 ходов, без бустеров), бесконечный режим, «Луг» (мини-игры, закрыт). |
| **Пчёлы** | **Все / Наряды**, карточка пчелы (уровень, прогресс, наряды, улучшение). |
| **Сюрпризы** | **Сундуки / Лавка / Альбом**. Сундуки: готовая сота, шансы, гарантия (эпик 10, легенда 30), прогресс остальных. Отдельный экран открытия соты. Лавка: вещи, бустеры, фрагменты за пыльцу. Альбом: страницы с бонусами. |
| **Задания** | 3 задания дня с полосками прогресса и бонус за все 3, **недельный сундук с кнопкой «Забрать»**, награда за вход (7 дней, серия), заморозка серии, статистика. |

Сверху на всех экранах только **мёд и шестерёнка**.

Отдельные экраны: **Настройки** (язык, звук, вибрация, уведомления и тихие часы, сохранение, **пригласить друга**, обновление, о игре) и **экран раунда** головоломки. При первом запуске показывается **выбор языка**.

## Принятые решения
- Недельный сундук забирается во вкладке **«Задания»**, а не в «Сюрпризах».
- Головоломка выходных перенесена во вкладку **«Играть»**, рядом с пазлом дня.
- «Пригласить друга» перенесено в **Настройки**.
- Альбом перенесён из «Пчёл» в **«Сюрпризы»**.
- Лавка **честная**: только за пыльцу и молочко, без давления и навязчивых предложений. Позже возможны необязательная косметика и «поддержать разработчика».
- Заморозка серии перенесена в «Задания», рядом с серией.
- Обычные равные вкладки, «Играть» специально не выделяется. Сад остаётся внутри «Улья».

## Файлы
- `screens/` — 14 экранов, 390×844 @3x.
- `screens-360/` — те же экраны на ширине 360.
- `overviews/` — сводные картинки.
- `src/` — генератор: HTML/CSS → headless Chrome. В `src/a/` копии нужных ассетов.
  - `python3 final.py && ./render.sh && python3 overviews.py`
  - `final.py` собирает экраны на основе `g2.py`, `g7.py` и `g8.py` (промежуточные версии из итераций макетов).

## Известные мелочи
На ширине 360 часть декораций и улей стоят на фиксированных местах и немного смещаются. В игре их нужно будет раскладывать относительно ширины экрана.
