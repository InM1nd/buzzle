# Передача прототипа Claude

Актуальная версия: **live-year-v10/**, ревизия панелей 2. Остальные папки — сохранённые варианты дизайна.

## Запуск
Из корня репозитория: `python3 -m http.server 8110 --directory design`.
Открыть http://127.0.0.1:8110/hive-run/live-year-v10/?single=1 . Без single — галерея с пояснениями.
Проверка: `node design/hive-run/live-year-v10/engine.test.mjs`.

## Файлы
- live-year-v10/engine.mjs — симуляция одного года, README.ru.md описывает тестовые правила.
- live-year-v10/app.mjs, style.css — браузерный интерфейс, сбор, назначения −/+, окна, пауза.
- live-year-v10/main.png, preview.png — актуальный вид; panel-review-before.css — прежние панели.
- assets/ — картинки и шрифты с лицензией; ui-options-v5/backgrounds/ — сезонные фоны.
- v2–v9 и корневые PNG — история вариантов. Корневой README описывает первоначальный дизайн; для текущей версии приоритет у live-year-v10/README.ru.md.

## Пожелания владельца
Основа — существующий улей Buzzle и его ассеты. Детализированные новые соты и тяжёлые текстурные панели не понравились. Материал панелей v9 отклонён. Банка v10 понравилась и сохранена. Последняя ревизия HUD и кнопок работ ещё ожидает оценки владельца. Весь визуал утверждённым не считать. Назначения через −/+ предпочтительнее перетаскивания. Сезонные фоны разрешены.

Вдохновение Wild Hive: тап по соте собирает мёд в банку; вылазки приносят пыльцу, работницы превращают её в мёд; матка периодически выводит пчёл, рост ускоряется мёдом; пчёлы едят из банки. Виды мёда учитываются раздельно, но в демке имеют одинаковую ценность.

## Открытые вопросы
1. Удобство на телефоне: размер сот, частота тапов и кормлений, нижнее управление, читаемость таймеров. Браузерная проверка не заменяет устройство.
2. Живое время выбрано для пробы по описанию владельца; финальная модель времени и длительность ещё не утверждены. Коэффициенты тестовые.
3. Забег на 3–4 года, растущая квота, модификаторы, сохранение партии, награды и дневной лимит ещё не реализованы и требуют обсуждения.
4. Весна использует летний фон. Android/Telegram на устройствах не проверялись.

Прототип не подключён к основной игре. Сохранения, экономика, production src/ и assets/ этой веткой не меняются. Не переносить тестовые правила в основную игру без согласования.
