# Бантик и очки Жужи · восемь направлений · кандидат v1

Подготовлены по восемь композиций каждого аксессуара. Это не 16 новых рисунков: бантик скрыт в дальнем профиле и задних видах, а у очков со спины видны только оригинальные коричневые дужки за головой. Новые рисунки: три вида бантика и шесть видов оправы/дужек.

Инструмент: встроенный image_gen.imagegen, прозрачный фон, два референса — утверждённый аксессуар и целевая голая пчела. Точные промпты, пути, посадки и таблица видимости сохранены в manifest.json. Спина и бока предметов придуманы по фронтальному эталону, ещё не утверждены.

Ракурс в три четверти спереди справа сохраняет исходные PNG, посадки и поворот бантика на 15° из ReferenceBeeAccessories.tsx. Тела не перерисованы. Левые тела — прежние зеркальные копии голой Жужи; аксессуары генерируются независимо.

Оправа имеет прозрачные отверстия, исходные глаза остаются видны. В боковом виде ближняя линза показана узким овалом с дужкой, сзади — дужки без переноса фронтальной оправы на затылок. На задних трёх четвертях точность расположения дужки относительно крыла требует визуальной оценки.

Бантик закреплён немного к анатомически левому боку передней части корпуса. В левом профиле виден его узкий край, в правом и задних видах скрыт. Отдельный слой невидимого бантика пуст; сама пчела остаётся прежней.

Нормализованные копии -view.png 512×512 используют общий центр корпуса. Восемь дискретных кадров дают ступенчатое вращение. Свет зеркальных тел меняет сторону. В основную игру не подключено. Наушники, нимб и примерки на других видах пчёл ещё впереди.

Профильная оправа механически разделена на ободок и дужку: ободок выровнен по исходному глазу, дужка отдельно подогнана к нему. Точные source_box и mount сохранены в fit_parts; общий placement у этих кадров пуст. Новые задние дужки повторно сгенерированы без золотых колец. Для скрытия дужки под ближним крылом использована исходная маска крыла из прототипа разворота.
