# Зимние пчёлы v4 · виды сзади и общий разворот

29.10.2026. Кандидаты на просмотр, не выбранные и не подключённые персонажи.

Новые изображения:
- bee-snow-back.png / .webp — снежная пчёлка, строго сзади.
- bee-gingerbread-back.png / .webp — пряничная пчёлка, строго сзади.

Для удобства в набор скопированы без изменения анфас, три четверти и профиль обеих пчёл из v2/v3. Всего восемь PNG и восемь WebP. Каждый PNG 1024×1024 RGBA, WebP без потерь.

- preview.png — два новых вида рядом с исходным видом Жужи сзади, светлый/ночной фон, 64/96 px.
- turnaround.png — обе пчёлки по четыре ракурса: анфас, три четверти, профиль, сзади.

Снежинка снежной и пуговки пряничной относятся к передней части тела и сзади не дублируются. У пряничной глазурь продолжается по краю полоски, у снежной сохранена кремово-черничная палитра. Исходный back.png Жужи — референс геометрии, анфас v1 — референс дизайна.

Это цельные концепт-спрайты. Четыре ракурса не являются совмещёнными кадрами анимации. Задние три четверти, вид сверху, независимые слои тела/крыльев, примерки нарядов и игровое подключение пока не подготовлены. Редкость, бонусы, имена и способ получения не назначены.

sources/ хранит две новые оригинальные генерации, generation.json — их промпты/референсы. Промпты ранних ракурсов остаются в v1–v3. checks.json — технические проверки новых экспортов. Копирование ранних изображений проверено побайтно. После imagegen только поля, пропорциональный размер и обзорные листы. Production assets/ и src/ не менялись.
