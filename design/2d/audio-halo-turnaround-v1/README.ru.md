# Наушники и нимб Жужи · восемь направлений · кандидат v1

16 примерок, общий лист compare.png, отдельные листы двух предметов, прозрачные PNG 1366×1151 и выровненные копии 512×512. В превью можно выбрать предмет, снять его, менять направление и запустить круг из восьми кадров. В игру не подключено, взмахов и моргания здесь нет.

Семь новых рисунков наушников созданы встроенным image_gen.imagegen: transparent_background=true, два референса — выбранные наушники и целевой ракурс голой Жужи. Точные промпты, пути генераций, обрезка и координаты посадки находятся в manifest.json. Скрытые настройки модели инструмент не предоставляет. Профиль, спина и левые стороны аксессуара придуманы по исходному рисунку; требуется оценка владельца.

Наушники в прежних трёх четвертях справа — точная копия принятой примерки headphones-on-zhuzha-preview.png. Для новых видов дальняя чашка вынесена за тело; ближняя чашка и ободок перед ним. Разделение выполнено прямоугольными областями исходных пикселей, без перерисовки. Это черновая маска, перед интеграцией нужны более точные контуры, проверка пересечения крыльев и совместимости с головными уборами. Наушники изменяют видимую ширину головы между рисунками — оценить это при вращении.

Для нимба новых генераций нет: одно осесимметричное кольцо из halo-and-resources-v2, одинаковая ширина 700 px и высота 146 px. При повороте вокруг вертикали горизонтальная окружность сохраняет проекцию, поэтому меняется только её положение относительно усиков. Исходные rear/front части масштабируются вместе; порядок: задняя дуга → исходная пчела → передняя дуга. Координаты каждого вида сохранены. source-halo*.png — исходные рисунки/слои, halo-ANGLE-front/rear.png — готовые слои на полном холсте. В профилях кольцо опущено, чтобы усики проходили внутри.

Тела всех восьми ракурсов скопированы из предыдущего этапа без изменения, проверены SHA-256. Левые тела по-прежнему зеркальные: свет на них меняет сторону. Общий центр корпуса выровнен по прежним anchors; восемь кадров дают ступенчатый разворот. Новая работа сохранена локально, отправка на GitHub этим этапом не выполнялась.

Проверка: 16 кадров загрузились в браузере, замкнутый круг, снятие аксессуара, автоматический разворот и остановка работают. На ширине 375 и 320 px нет горизонтального переполнения. Принятая примерка наушников справа совпадает с исходником побайтно. Дальше — примерки аксессуаров на остальных видах пчёл, доработка сот под сетку и интеграция.
