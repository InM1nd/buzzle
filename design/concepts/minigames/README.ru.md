# Концепты мини-игр (v1.8+, предварительно)

15 октября 2026. Александр отклонил «Свечную мастерскую» и «Танец разведчицы», попросил нарисовать «Сортировку пыльцы» и «Защиту улья» и придумать ещё идеи. **Это концепт-кадры, собранные из ассетов v1.5, а не код игры и не финальный арт.** Все цифры условные, решение по играм не принято.

## Нарисованные концепты (390×844, @2x)

| Игра | Кадры | Идея |
|---|---|---|
| **Сортировка пыльцы** | `pollen-sorting-1-gameplay.png`, `pollen-sorting-2-result.png` | Пчёлы летят одна за другой с пыльцой разных цветов. Игрок перетаскивает пчелу в банку нужного цвета (подсолнух, василёк, лаванда, клевер), пока не переполнился склад. Комбо за серию без ошибок, таймер на смену (около 60–90 с). |
| **Защита улья** | `hive-defense-1-gameplay.png`, `hive-defense-2-wave-result.png` | Tower-defense-lite. Осы и шершень-вожак идут по тропе к дереву с ульем, игрок ставит на площадки пчёл-стражей (за мёд), липкие капли и бочки-ловушки. Волна 3 из 5, здоровье улья, награды после волны. Сессия около 2–3 минут. |
| **Цветочное слияние** (новая идея) | `flower-merge-1-gameplay.png`, `flower-merge-2-result.png` | Как «арбузная» игра: пчела бросает цветок в ящик, два одинаковых сливаются в следующий (росток → мята → лаванда → василёк → подсолнух → золотой подсолнух). Нельзя переполнить границу. Сессия около 3 минут. |
| **Медовая тропа** (новая идея) | `honey-path-1-gameplay.png`, `honey-path-2-result.png` | Логическая игра на сотах: поворачивай соты с каналами, чтобы мёд из банки сверху дошёл до всех пустых баночек. Ограничение по ходам, звёзды. Сессия 1–3 минуты, уровни. |

## Что взято из ассетов, а что нарисовано
- **Взято:** фон поляны (`environment-honey-crystal-v1/garden-background`) и фон улья, соты (`comb_empty`), банка мёда, цветы и росток (`assets/art/garden`), звёзды, иконки, украшения, дерево-улей (соты из игры), пчёлы из слоёв `assets/art/turn` (тело + крылья + корона), шрифт Nunito.
- **Нарисовано (SVG/CSS, арта пока нет):** стеклянные банки, шарики пыльцы, тропа, площадки для стражей, деревянный ящик и круглые «пузыри» цветков, каналы мёда в сотах, карточки результата, кнопки, HUD, дерево.
- **Враги в «Защите улья»** — это перекрашенные пчёлы Бориса, Марго и Клеверы (тёмно-фиолетовые и красные) с нарисованными бровями. Настоящих ос и шершней в ассетах нет, их нужно рисовать отдельно.
- Физика в «Цветочном слиянии» — быстрый расчёт для кадра, не геймплейный код.

## Сборка
`src/game_*.py` создают HTML (общие функции в `src/common.py`, `lib.py`, `tree.py`), `src/render.sh` снимает его headless Chrome. Скриптам нужна папка `a/` с копиями ассетов и готовыми композитами пчёл рядом; в репозиторий она не входит.
