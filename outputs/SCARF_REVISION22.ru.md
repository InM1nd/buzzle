# Левый край шарфа · revision=22

Просмотр: http://127.0.0.1:8099/?beePreview=1&revision=22

Левая часть шарфа поднята вверх вдоль бока. Наклон постепенно уменьшается к узлу; узел и хвостики справа сохраняют положение. Сам PNG не менялся: используется scarf-fitted-v4.png. Передняя полоса сохраняет толщину, левый край немного приближен к телу. Добавлено место для поднятого края, чтобы он не обрезался при отображении. Корона сохранена без изменений.

Проверены Пушинка крупно и сравнение с Жужей. Проверка типов, 12 тестов аксессуаров и веб-экспорт прошли. Посадка ожидает визуального одобрения, физическое устройство пока не проверено.
