# Венок и берет · восемь направлений · кандидат v1

Подготовлены 14 независимых ракурсов аксессуаров (по семь для каждого). Тела пчёл не перерисованы: скопированы из cloth-turnaround-v2. Три левых тела являются ранее созданными зеркальными голыми пчёлами, аксессуары генерируются для них отдельно.

В три четверти спереди справа используются прежние PNG и посадки ReferenceBeeAccessories: венок [540,265,440,195], берет [510,210,540,230]. Два преобразования венка, выравнивающие его центр, воспроизведены из существующего кода. Маска усиков берета [430,0,670,285] также взята из ReferenceBee. Это сохраняет ранее утверждённую посадку; итоговые композиции создаются заново, исходные ассеты не изменены.

Новые рисунки: image_gen.imagegen, прозрачный фон, утверждённый аксессуар и целевой ракурс головы как референсы. Точные промпты, пути, размеры посадки и границы масок — manifest.json. Генератор не гарантирует одну и ту же геометрию: расположение отдельных листьев, цветов и граней может дрейфовать. Спина головных уборов придумана по фронтальному эталону, ещё не утверждена.

Композиция: исходная пчела → головной убор → оригинальные усики выше границы поверхности. Маска новых ракурсов механически извлекает коричневые пиксели в верхней области. Скрытые стебли не дорисованы; отверстия и швы в ткани вокруг усиков пока не разработаны.

Нормализованные копии -view.png 512×512 используют общий центр корпуса из существующего разворота. Восемь кадров дают ступенчатый поворот; у зеркальных тел меняется направление света. Взмахи и моргание не входят в эту примерку.

Это кандидаты для проверки посадки, объёма венка, наклона берета и появления усиков. В основную игру не подключены. Бантик, очки, наушники, нимб и посадки на других видах пчёл ещё впереди.
