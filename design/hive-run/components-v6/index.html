Сначала — понятные числа и управление

Одинаковые данные, два способа переноса пчёл. Нажми кнопки: оба примера работают независимо.

Сравнить на одном листеПредыдущие варианты сохранены

A · Крупные счётчики

Освободи пчёл через «−», затем добавь через «+». Свободный остаток виден у кнопки сохранения.

B · Прямой перенос

Выбери, откуда забрать пчелу, затем нажми «Сюда +1» у другой работы. Свободный остаток не нужен.

Прототип компонентов для выбора направления. Это не утверждённый интерфейс и не новая игровая механика. Числа иллюстративны.
