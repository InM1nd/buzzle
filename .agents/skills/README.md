# Agent skills (Codex / Agent Skills format)

Six game-dev skills copied from [gamedev-skills/awesome-gamedev-agent-skills](https://github.com/gamedev-skills/awesome-gamedev-agent-skills) (commit 19d93f9, Apache-2.0, see LICENSE/NOTICE files here). Picked for Buzzle and the planned Hive Run mode (v1.8):

- save-systems: saving an unfinished run between sessions, save migrations
- roguelike: run structure, run economy, permadeath
- procedural-gen: seeded generation of meadows and events
- game-feel: responsiveness, juice, feedback
- game-ui-ux: portrait mobile UI and HUD
- performance-optimization: frame budget on phones

Buzzle is React Native/Expo, which those skills do not target directly; use their engine-neutral parts. The upstream router and engine-specific skills are intentionally not included.
