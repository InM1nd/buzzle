## Сборка

Использовать среду Android-сборки 1.4.1 и **тот же** `keystore/bzz-release.jks` и `keystore/keystore.properties`. Не создавать другой ключ и не добавлять ключи/пароли в Git. Ожидаемый SHA-256 сертификата:

`79:0C:F7:3C:A6:6C:F9:7B:E3:A1:0C:27:0E:79:6F:1C:9D:6C:67:57:A2:39:F5:72:3B:6E:97:AE:E1:37:7B:DC`

```bash
git switch v1.6
git pull --ff-only origin v1.6
npm ci
npm run typecheck
npm test
npm run test:ui -- --runInBand
export EXPO_PUBLIC_BZZ_DEV=1   # дев-сборка: в Настройках появляется тумблер «DEV · Хеллоуин»
CI=1 npx expo prebuild --platform android --no-install --clean   # --clean: старый android/ мог остаться с versionCode 23
bash scripts/configure-android.sh
cd android
./gradlew assembleRelease --no-daemon --console=plain
cd ..
cp android/app/build/outputs/apk/release/app-release.apk Buzzle-v1.5.5-dev.apk
bash scripts/verify-apk.sh Buzzle-v1.5.5-dev.apk
```

Параметры уже выставлены: `versionName=1.5.5`, `versionCode=24`, `applicationId=com.zabolotny.bzz`, arm64, R8/resource shrinking, `expo.useLegacyPackaging=false`. После prebuild обязательно выполнить configure-android.sh: он подключает прежний release signing и настройки упаковки.

## До загрузки

- Проверить фактический package/version через aapt и сертификат через apksigner, а не только конфигурацию проекта. Не загружать debug/unsigned APK или APK с другим сертификатом.
- Нативные `.so` должны быть Stored/несжатыми и выровненными как у 1.4.1; проверить zipalign и ELF alignment.
- Измерить размер APK: цель ≤25 МБ, без понижения качества пчёл. Если размер больше — найти вклад библиотек/ресурсов и описать результат. Не уменьшать новые портреты и лётные слои вслепую.
- По возможности установить поверх 1.4.1 с тестовым прогрессом и проверить сохранение прогресса, шрифты, WebP, крылья/наряды, поля ввода и аппаратную кнопку назад. Не менять логику, экономику и миграции ради сборки.
- 127 игровых + 43 UI-теста проходят. Сверка версии теперь допускает `versionName "1.5.5-dev"`; если в `android/` устаревший prebuild, тест не падает, а пишет диагностику «prebuild is stale» (лечится `prebuild --clean`). Нативная сборка на стороне Claude не выполнена: нет Android SDK и ключа.
- **Переход в ночь (проверить на устройстве, лучше на 120 Гц):**
  - Режим ивента «Всегда», в Настройках «DEV · Повторить переход в ночь». Около 2,6 с цвета фона, карточек, текста и таббара плавно перетекают из classic в midnight, фон сцены кроссфейдится, сверху луна, летучие мыши и светлячки. Не должно быть рывка в начале и «двойного» интерфейса в конце.
  - Баннер «Сладость или гадость», карточка ивента и Ночной полёт появляются только после перехода.
  - Обратный переход: режим «Выкл.» и та же кнопка, около 1,6 с без мышей.
  - В системе включить «Уменьшить движение»: короткий фейд около 0,45 с без акцентов.
  - Тема «Классика»: меняются только фоны.
  - Во время перехода тапы не проходят.
- Длинные подписи на узких кнопках («Закрыто», «Только в сб и вс») переносятся на 2 строки и уменьшаются; проверить на узком экране в en/uk/ru.
- Ивент включается сам 20.10 и идёт до 9.11 включительно; в дев-сборке режим ивента в Настройках: «Всегда / Выкл. / Календарь». Проверить календарь в APK: режим «Календарь» и дата телефона 20.10–9.11.

## Публикация

Создать **prerelease** v1.5.5-dev (или заменить APK в нём, если уже есть). Обычный релиз не создавать, prerelease в стабильный не переводить. Основной апдейтер не должен предлагать этот dev APK. GitHub Pages в рамках этой задачи не деплоить.

```bash
gh release view v1.5.5-dev --repo InM1nd/buzzle >/dev/null 2>&1 || gh release create v1.5.5-dev --repo InM1nd/buzzle --prerelease --target v1.6 --title "1.5.5-dev" --notes "pre-release for testing"
test "$(gh release view v1.5.5-dev --repo InM1nd/buzzle --json isPrerelease --jq .isPrerelease)" = "true" || exit 1
gh release upload v1.5.5-dev Buzzle-v1.5.5-dev.apk --repo InM1nd/buzzle --clobber
```

В описании prerelease отметить точный commit сборки и выполненные проверки. Вернуть владельцу ссылку на APK, размер файла, versionCode и результат проверки подписи. Если ключ/среда недоступны, сообщить об этом; другим ключом не подменять.
