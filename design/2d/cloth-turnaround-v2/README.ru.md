# Шарф и сумка: восемь направлений · v2

Пять прежних композиций скопированы из v1 без изменений. Левые тела — механически зеркальные голые пчёлы; исходные тела и игра не изменены. Асимметричные аксессуары рисуются отдельно, а не зеркалятся вместе с пчелой.

Генерация: встроенный image_gen.imagegen, прозрачный фон, по два референса. Пять новых PNG: три вида шарфа и два вида сумки. В левом профиле сумка скрыта телом; использована уже имеющаяся задняя панель, расположенная на дальнем слое. Точные промпты, источники, посадки и кривые ремня в manifest.json.

Композиция сумки: дальняя сумка → исходное тело → видимая часть ремня. Ремень сохраняет векторный материал и толщину утверждённого аксессуара; кривые адаптированы по ракурсам. Это приблизительная художественная посадка; физическое расположение креплений пока не подтверждено 3D.

Для просмотра создаются отдельные нормализованные копии -view.png на холсте 512×512 с общим центром корпуса. Параметры центра и масштаба взяты из существующего прототипа разворота; для левых ракурсов центры отражены. Полноразмерные композиции не меняются.

Восемь кадров дают ступенчатый поворот. Свет зеркальных базовых тел меняет сторону. Сходство материала и формы новых аксессуаров, скрытие сумки и узла, стыки ремня требуют оценки владельца. Пока не подключено к основной игре; остальные аксессуары и виды пчёл впереди.
