# Жужа · общая проверка аксессуаров

Восемь предметов на восьми направлениях: корона, венок, берет, шарф, сумка, бантик, очки, нимб. Прежние готовые PNG скопированы без изменения. Корона выровнена по общему центру корпуса; левые короны зеркальные, камни тоже отражены. Превью открывается на прежних трёх четвертях справа. Новых рисунков нет.

Наушники исключены владельцем из дальнейшего использования и интеграции; их исходники и исторические примерки сохраняются. Очки и нимб Пушинки/Бориса оценены как приемлемые. Остальные шесть аксессуаров этих двух видов требуют пересмотра на всех направлениях. Перенос на остальных пчёл откладываем до разбора посадок. Оригинальные ракурсы тела сохраняем.

Это отдельная страница проверки рисунков, без изменения игры. Можно выбрать предмет, ракурс, снять предмет и запустить круг из восьми кадров. Свет зеркальных тел меняет сторону; независимые ракурсы аксессуаров могут иметь несогласованную перспективу. Не считать этот лист новым утверждением ранее созданных кандидатов.
