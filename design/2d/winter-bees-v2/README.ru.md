# Зимние пчёлы v2 · снежная, три ракурса

29.10.2026. Расширение одного из двух направлений winter-bees-v1. Не означает финальный выбор или новую игровую пчелу.

- bee-snow-q3-front.png / .webp — новый ракурс в три четверти.
- bee-snow-side.png / .webp — новый профиль вправо.
- bee-snow-front.png / .webp — анфас из v1 без изменений.
- preview.png — три ракурса, светлый/ночной фон и 64/96 px.
- profile-compare.png — канонический профиль Жужи рядом со снежной, чтобы оценить геометрию крыльев/усиков.

PNG 1024×1024 RGBA, lossless WebP. Палитра кремово-черничная, тонкие медовые жилки на жемчужных крыльях. Снежинка остаётся на передней полоске, в профиль видна частично. Базовые ракурсы Жужи задают геометрию; цвет и маркировка взяты из снежной пчелы v1.

Цельные концепт-спрайты, НЕ независимые тело/крылья. Исходные пчёлы не заменены. Задние ракурсы, слои для анимации, наряды и игровое подключение пока не подготовлены. Пряничная альтернатива остаётся в v1; её остальные ракурсы ещё не нарисованы. Редкость, имя, бонусы и способ получения не назначались.

sources/ — оригиналы; generation.json — промпты/референсы; checks.json — размеры/альфа и совпадение PNG/WebP. После imagegen только поля, пропорциональный размер и листы сравнения. Production assets/ и src/ не менялись.
