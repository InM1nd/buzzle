# Оленьи рожки · отдельный слой, анфас

19.11.2026. Кандидат на просмотр. Два коротких медово-карамельных рожка на тонком красном ободке, по дизайну winter-wardrobe-v3. Пчела — каноническая Жужа анфас, исходник не перерисован.

- antlers-front.png/.webp — самостоятельный аксессуар RGBA в исходном разрешении после обрезки полей.
- antlers-fitted.png/.webp — тот же аксессуар на полном холсте Жужи 1366×1151, начало (0,0).
- antennae-overlay.png/.webp — сохранённые оригинальные фрагменты усиков только в области пересечения с аксессуаром; полный холст, без сдвигов. Это привязанный к текущей примерке слой.
- fitting-front.png — статическая сборка для просмотра.
- preview.png — светлый/ночной фон, самостоятельный слой и примерка, миниатюры 64/96/128 px.
- layout.json — координаты и порядок слоёв. checks.json — размеры/альфа/проверки экспорта и неизменности вне области аксессуара.
- sources/ и generation.json — оригинал встроенного imagegen, полный промпт и референс.

Порядок сборки: исходная Жужа → antlers-fitted → antennae-overlay. Все слои масштабировать одной трансформацией. Не обрезать готовые слои по отдельности. Усики и крылья не переставлялись; геометрия тела, лицо и лапки не менялись. Для профиля и три четверти нужны свои изображения аксессуара. Старые примерки сохранены. assets/ и src/ не менялись, игрового подключения нет.
