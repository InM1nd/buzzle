# Объединённый главный экран · v8

На доработке, не утверждён. Один вариант вместо очередной пары. Пользователь попросил сочетание A/B из main-screen-v7.

## Что объединено
- Из A: улей в центре, свободная сцена и знакомые игровые соты/пчёлы.
- Из B: квота рядом с нижним действием.
- Управление «−/+» — выбранное пользователем, в отдельной панели. Прямой перенос не используется.
- Запасы сверху: крупные 12/48, подписи отдельно. Мёд показан в блоке квоты, не продублирован в верхней полосе.
- Год и сезон в одной плашке; 4 отметки показывают место сезона в году.
- Квота: запас 132/180, срок и одна строка прогноза. Золотая полоса — запас сейчас, светлая — прогноз; текст сохраняет смысл без цвета. Прогноз — часть блока цели, не отдельная карточка.
- Строка работ показывает назначение и открывает редактирование.
- Основная кнопка сначала «Подготовить сезон», после сохранения — «Начать зиму/сезон». Сохранение плана не запускает ход. Это UX-предложение, не новая подтверждённая игровая формула.
- При сохранении плана короткий подъём пчёл подчёркивает обратную связь; reduced-motion отключает эффект. Никаких постоянных декоративных циклов.

## Источники и рамки
Главная опора — реальный улей Buzzle и пользовательские правки v7. Nunito, оригинальные пчёлы, comb/comb_empty, нектар, мёд, клевер из ../assets/. Готовые фоны из ../ui-options-v5/backgrounds/: лето, осень, зимний день и вечер. Дневная зима содержит праздничные ветки исходного baseline — новые украшения не добавлялись. Весеннего отдельного фона в этом макете нет. Новые иллюстрации не генерировались. refero-design использован для иерархии, акцентов и проверки; визуальная основа — существующая игра.

Механика не расширялась. Условные цифры из v4: план 4/6/2 даёт 168 мёда, план 2/8/2 даёт 180; прогноз без случайных потерь. Работа пчёл считается с условными коэффициентами, не утверждённым балансом. После запуска показывается лист результата; следующий сезон и списание квоты не выполняются. Возврат сохраняет сцену исходного примера, чтобы сравнивать UI. Луг один, указан как «Луг примера».
Сохранить можно и план, не закрывающий квоту: интерфейс сообщает нехватку, но не вводит новое правило запрета такого хода. Свободные пчёлы и нехватка нектара блокируют сохранение только в рамках демонстрационного назначения.
Код основной игры, assets/, экономика, сохранения и сборки не менялись. Все предыдущие версии сохранены.

## Файлы
- index.html — один кликабельный гибрид, выбор готового фона, описание решений.
- ?single=1 — телефон; ?state=prepared — сохранённый план 2/8/2; ?view=plan — открытые счётчики.
- main.png — исходный главный экран.
- prepared.png — после сохранения 2/8/2.
- plan.png — отдельная панель «−/+».
- evening.png — тот же главный экран на зимнем вечернем фоне.
- flow.png — три состояния в порядке действия.
- Все одиночные PNG 1080×1920.

## Проверка
24 сочетания: 360/390/430 ×640, 4 фона, до/после подготовки. Нет отсутствующих картинок, переполнения, пересечения сот и пчёл с запасами/квотой и кнопок меньше 44×44. Пройден кликами путь: подготовка → −2 с вылазки → +2 на переработку → сохранение → смена кнопки → запуск → результат → возврат; также открытие подробностей квоты. Панель назначения помещается при 360×640 без прокрутки. Удобство для игроков и баланс этим не доказаны.
