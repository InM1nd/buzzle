# Растения «Медовый кристалл» — первая партия, v1

13 октября 2026. Семь новых PNG для визуальной оценки владельцем. Основная игра не изменена.

## Комплект
sprout.png — общий росток.
sunflower_bud.png / sunflower_bloom.png — подсолнух.
clover_bud.png / clover_bloom.png — клевер.
lavender_bud.png / lavender_bloom.png — лаванда.
compare.png — пары стадий рядом с Жужей и миниатюры 32 / 48 / 72 px.
manifest.json — полные промпты каждого изображения, источники результатов.

## Получение
Встроенный image_gen, transparent_background=true.
Росток и цветущие растения созданы отдельными вызовами по Жуже, принятому декору и макету сада.
Каждый бутон получен отдельным редактированием соответствующего цветущего растения с требованием сохранить стебли, листья, камеру, освещение и положение на холсте.
Исходные выбранные PNG скопированы без изменения рисунка и прозрачности.
Альфа-канал всех файлов содержит 0 и 255.
Холсты стадий одной пары совпадают: подсолнух 1144×1375, клевер и лаванда 1312×1199. Росток 1366×1152.
Коллаж сохраняет полный холст в крупных парах; миниатюры обрезаны по прозрачным полям для проверки читаемости.

## Визуальная сверка
У всех пар узнаваемая общая архитектура: подсолнух с двумя листьями, клевер с двумя тройными листовыми группами, лаванда с тремя колосками.
Закрытые и открытые цветки легко отличаются. У подсолнуха и клевера листья близки по позиции и масштабу.
Редактирование не гарантирует пиксельную неподвижность: отдельные грани, небольшие положения листьев и основание лаванды слегка изменились. Перед игровым подключением нужно выровнять точку посадки и проверить переключение стадий в грядке.
Росток имеет два листа и центральную почку; без земли, корней и горшка.
Земля остаётся отдельной задачей. Пары ожидают оценки владельца; автоматической готовности к продакшну нет.
