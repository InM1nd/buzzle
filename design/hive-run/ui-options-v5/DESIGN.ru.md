# Два направления v5 · источники и решения

На просмотре. Предыдущие макеты сохранены. Не интеграция в игру.

## Основа и визуальные ограничения
Главный источник — существующий Buzzle: screens/v1.5/01-hive.png, реальные comb/comb_empty и пчёлы. Сохраняем свободную сетку на фоне, тёплый свет, Nunito, медовую основную кнопку, без новых детализированных строений. Второй источник — ранее понравившийся blueberry-world: outputs/buzzle-winter-ui-v1/blueberry-winter-evening.png. Заимствуем только черничные поверхности #282f59 и кремовый текст, а не плотность старого зимнего экрана с улучшениями. Третья опора — последовательность v4: распределение → луг → сезон → итог. На главном оставляем цель и ближайшее действие.
Навык refero-design: доступны локальные craft references и пользовательские материалы; живой Refero MCP не настроен. Не использованы внешние несвязанные стилевые референсы.

| Решение | Источник | Зачем |
|---|---|---|
| Крупный улей без зданий | Прямая просьба пользователя, реальный HiveScreen | Знакомый игровой объект, меньше декора |
| Сезонные фоны без перерисовки | Готовые лето/осень/зима | Смена сезона без нового художественного языка |
| Одна нижняя панель вместо стопки карточек | Обратная связь пользователя о перегруженности | Роли, редактирование и запуск в одной зоне |
| Подробности назначения в выдвижной панели | Контекст одного действия, крупные цели касания | Сцена остаётся частью игры, не отдельная таблица |
| A: три ряда назначения | v4, прямое сравнение всех групп | Меньше переходов при переносе пчёл |
| B: фокус на одной роли | Снижение плотности, отдельные роли | Крупнее объяснение и счётчик; больше переключений |
| Жёлтый — основное действие/выбранная роль | Реальная игра, черничный сезонный макет | Не использовать акцент для рамок всех элементов |

## Фоны
backgrounds/summer.webp — экспорт outputs/hive-run/assets/hive_bg.webp.
backgrounds/autumn.webp — assets/art/halloween/hive_bg_autumn.webp основного репозитория. Осенний фон содержит тыквы по краям, новый Хеллоуин-декор не добавлялся.
backgrounds/winter-day.webp и winter-evening.webp — exports из outputs/buzzle-winter-unified-v3/baseline/winter-{day,evening}/hive.png. Выбраны знакомые исходные дневной/вечерний улей; альтернативные наборы не заменяют их автоматически.
День и вечер — два состояния зимы, не две разные игровые стадии. Весеннего отдельного фона в этот набор не добавлено. Если потребуется весенний образ, сначала выберем, достаточно ли летнего, либо нужна новая генерация.
Новые арты не понадобились. Все PNG/WebP и шрифты используются из существующих материалов; сравнение нарисовано браузерной компоновкой, не генерацией новых пчёл.

## Что можно попробовать
Два независимых примера рядом, сезонный переключатель, открытие/закрытие назначения, перенос пчёл через −/+, выбор роли в B, сохранение плана и просмотр условного результата. Кнопка «?» объясняет цикл. «Луг» открывает информацию о текущем луге; других локаций здесь нет. Кнопка назад объясняет границы примера.
Числа и формулы — из v4 только для сравнения UI. Случайные потери, бонусы и следующие годы не рассчитываются. Повторный пример сбрасывает данные; сохранений нет. Замена сезона меняет фон и подпись, не вводит сезонных коэффициентов.

## Что сравнить
A проще для переноса пчёл между группами: все количества перед глазами. B спокойнее на главном и даёт больше места объяснению одной работы; для перераспределения нужно переключать роли. Ни один вариант не утверждён и не заменяет основной UI.
