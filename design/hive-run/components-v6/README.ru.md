# Компоненты UI · v6

На просмотре. Изолированное сравнение компонентов, не следующий утверждённый главный экран. Пользователю не подошли компоненты v5; менять только фон/палитру недостаточно.

## Изменения
- Запасы показаны тремя равными блоками: крупная цифра, иконка и отдельная подпись, без подписей внутри длинных строк.
- Tabular numerals удерживают ширину числа при изменении. Nunito Bold/ExtraBold для текста, Black только для ключевых цифр.
- Квота отделяет 132 мёда сейчас от прогноза 168/180 после сезона. Тёмное заполнение — текущий запас, светлое — ожидаемое; числовые подписи дублируют смысл цвета.
- Общая светлая поверхность вместо отдельных скруглённых карточек для каждой работы. Названия и отдача выровнены по одной колонке.
- A: три крупных счётчика −/+, свободный остаток рядом с сохранением.
- B: выбрать источник нажатием на название работы, затем «Сюда +1» в целевой группе. Перенос сохраняет сумму 12, отдельного свободного остатка нет. Выбранный источник выделен и подписан «Отсюда».
- Кнопки не меньше 44×44, основное сохранение 50 px. Кнопка сверху сбрасывает пример (aria-label), а не открывает основную игру.

## Просмотр и файлы
index.html — оба метода рядом, кнопки работают. ?single=a или ?single=b — экран телефона. a.png, b.png — 1080×1920; compare.png — сравнение. Все прошлые варианты сохранены.

## Источники решений
База — существующие Nunito и игровые PNG Buzzle из ../assets/, зимний фон из ../ui-options-v5/backgrounds/winter-evening.webp. Фон оставлен только в верхней зоне: это изучение компонента, а не финальная компоновка главного экрана. Исходные пчёлы, мёд, клевер и нектар не перерисованы. refero-design/references/typography.md использован для иерархии чисел и подписей; SaaS-шрифт/палитра из примеров навыка не переносились. Пользовательская обратная связь задаёт отказ от мелких чисел, лишних карточек и неудобного промежуточного состояния при переносе. Внешние референсы не использованы, Refero MCP недоступен.

## Границы
Формулы — условный сценарий v4: 4/6/2 → 2/8/2 даёт 180 мёда, 0 нектара. Выводок округляется до пары. Прогноз без случайных потерь. Сохранение только отмечает план в памяти вкладки и не запускает сезон. Никаких изменений в основной игре, assets/, экономике или сохранениях. Новые картинки не генерировались; PNG — снимки браузерного UI.

## Проверка
Оба варианта просмотрены на 360/390/430 ×640. После сокращения инструкции B всё содержимое помещается при 360×640; кнопки ≥44×44. Проверен перенос 4/6/2 → 2/8/2 и сохранение в обоих вариантах, в B дополнительно смена источника и сохранение общей суммы 12. Это проверка взаимодействия макета, не доказательство удобства для игроков.
