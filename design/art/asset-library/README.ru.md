# Единая коллекция ассетов Buzzle

Постоянный локальный адрес: **http://127.0.0.1:8110/buzzle-style-board/**.

Каталог заменяет стартовую страницу прежней доски, не меняя её адрес. Предыдущая доска доступна на вкладке «Сравнение стилей» и в `styles.html`. Сохранённые `all-styles.png` и `overview.png` остаются на месте.

## Что входит

Все PNG, WebP, JPEG, GIF и SVG из папок репозитория `assets`, `design`, `outputs`, включая архивные примерки, 3D-превью, макеты и исходные слои. Точные дубли сгруппированы по SHA-256; все исходные пути доступны в карточке. Файлы моделей, шрифты и код не показываются как рисунки.

По умолчанию показана основная коллекция, без архивных проб, исключённых предметов, сырых исходников, отдельных слоёв и проверочных скриншотов. «Все, включая архив» открывает полный индекс. Метаданные категорий и статусов определяются по папке и имени файла; это навигационные пометки, не автоматическое утверждение владельцем. «Рабочие файлы» означает расположение в assets, а не доказанное использование в экране игры.

Поиск понимает русские имена пчёл и основных предметов, английские имена файлов и исходные пути. Есть фильтры по разделу, стилю, сезону, пчеле, виду материала и статусу. Избранное хранится в текущем браузере. Для сравнения можно выбрать до четырёх изображений. В крупном просмотре открывается исходник, а не уменьшенная миниатюра.

## Правило для следующих добавлений

1. Сохранять новые игровые рисунки в `design/art/<набор>/`, ракурсы/слои в `design/2d/<набор>/`, промо в `design/brand/<набор>/`. Не заменять одобренный исходник новым экспериментом.
2. Сезонный набор обозначать `halloween` или другим явным именем в пути. Для экспериментов материала использовать `soft-crystal`, а в классификаторе дополнять правило нового стиля, если он новый.
3. Открыть постоянную ссылку и нажать «Обновить каталог». Сервер проверяет папки при обновлении и перезагрузке страницы, добавляет новые файлы, обновляет изменённые и убирает отсутствующие из индекса.
4. Проверить новые карточки, категорию, стиль и оригинал. При необходимости уточнить `classify` в `scripts/art_asset_catalog.py`.
5. Использовать эту ссылку для следующих обзоров коллекции; не создавать очередной отдельный каталог. Новые сравнительные листы сохранять в design — тогда они тоже будут видны в коллекции.

## Запуск и восстановление

Требования: Python 3.10+ и Pillow. Генератор не использует сетевых сервисов. Запускать из корня репозитория:

```sh
python3 scripts/art_asset_catalog.py --output ../../outputs/buzzle-style-board
python3 scripts/serve_asset_catalog.py --output ../../outputs/buzzle-style-board --port 8110 --open
```

В текущем workspace используется интерпретатор `../v15-python/bin/python`. Возле каталога также сохранён локальный запускатель `Открыть коллекцию Buzzle.command`.

Собранная копия находится в `outputs/buzzle-style-board` родительского workspace: `index.html`, `catalog.json`, `thumbs`, `files`. Она открывается и как локальный HTML-снимок без сервера; кнопка поиска новых файлов требует работающего локального сервера. Изображения для просмотра хранятся локально: оригиналы по возможности представлены жёсткими ссылками, иначе копиями; миниатюры создаются отдельно. Файлы игры не изменяются. В Git сохраняются генератор, шаблон и инструкция, а не ещё одна копия всей графики.
