# Текущий статус художественной проверки

Обе попытки 3D-моделирования отклонены владельцем: они не соответствуют выбранному референсу. Эти модели не являются согласованными ассетами.

По умолчанию тестовый экран теперь показывает «Спрайт по референсу»: цельное прозрачное изображение, выделенное из выбранного концепта инструментом генерации изображений. Это более близкий визуальный вариант, но не точная копия исходных пикселей и не готовая 3D-модель.

У спрайта фиксированы корона, крылья и ракурс. Он показывает уровень 10. Повороты, моргание и отдельные наряды для него отсутствуют; соответствующие переключатели скрыты. В улье может перемещаться целое изображение, без движения его частей. Проверить вид можно в сравнении, улье и коллекции. Старый вариант доступен под подписью «3D-попытка».

Необходимо согласовать сходство с концептом, затем отдельно выбрать и изготовить согласованный набор слоёв/ракурсов для анимации. Другие пчёлы и предметы ещё не перенесены.

# Рабочий прототип Жужи

Локальный просмотр: http://127.0.0.1:8099/?beePreview=1

После замечания о неверной модели переделаны профиль корпуса, пропорции лица, глаза, усики, полосы и корона по приложенному референсу Жужи. Это сделанная в Blender интерпретация концепта; точное художественное совпадение ещё требует оценки владельца. Остальные пчёлы, предметы и сад пока используют исходную графику.

## Что смотреть

1. В «Сравнении» исходная и новая Жужа показаны при одинаковых размерах. Внизу — размер возле сот. Кнопка «Крупно» показывает новую модель в увеличенном размере.
2. Включить «Автоповорот»: проверить крылья, моргание и плавность смены ракурсов. «Пауза» позволяет рассмотреть слои.
3. В «Нарядах» посмотреть все восемь аксессуаров. На уровне 5 появляются золотые крылья, на уровне 10 — корона. Венок, берет, наушники и ореол скрывают корону по существующим правилам игры.
4. В «Улье» и «Коллекции» переключить «Исходная / Новая». Новая графика применяется только к Жуже. Выбранный наряд теперь передаётся также пчеле в улье.
5. Оценить, читаются ли крылья и лицо на маленьком размере, подходят ли цвет и грани к фону и предметам. Это следующая точка художественной проверки.

## Файлы и запуск

`zhuzha-prototype-source.zip` содержит изменённые и добавленные файлы относительно версии `41b9a870ad0b0002d149fa7f7b5d1539aa9452f4` репозитория InM1nd/buzzle. Распаковать в отдельную копию этой версии. `zhuzha-prototype.blend` — редактируемая сцена.

Из папки проекта:

```sh
npm ci
npm run web
```

В открывшийся адрес добавить `?beePreview=1`. Для сохранённых скриншотов использована экспортированная web-сборка и существующий скрипт подключения Nunito из `scripts/web-screens/inject.py`.

Повторный рендер, при наличии Blender:

```sh
python3 scripts/bees3d/prototype.py jobs ../bee-prototype/renders > ../bee-prototype/jobs.json
blender -b -P scripts/bees3d/render_lowpoly.py -- ../bee-prototype/jobs.json
python3 scripts/bees3d/prototype.py pack ../bee-prototype/renders
```

Набор: пять ракурсов, отдельные тело и глаза, обычные и золотые крылья, корона и восемь нарядов. 75 слоёв WebP. Используется существующая анимация приложения; непрерывная 3D-анимация в игру не добавлена.

## Выполненные проверки

- TypeScript: успешно.
- Экспорт web-сборки: успешно.
- Браузер 412×892: сравнение, наряды, уровни, пауза, автоповорот, улей и коллекция.
- Автоматически переключены 162 сочетания: три уровня × шесть положений × девять вариантов наряда. Проверена успешная загрузка изображений; это не художественная оценка каждого сочетания.
- Консоль после окончательной сборки: нет ошибок. Остаётся обычное предупреждение React Native о выполнении анимации в JavaScript на web.
- LocalStorage тестового режима остался пустым.
- Общие тесты: 93/94 успешны. Проверка совпадения версий требует отсутствующий в репозитории генерируемый `android/app/build.gradle`. На исходной версии результат тот же.
- UI-тесты: 7/22 успешны. Остальные 15 ищут русские подписи при английском языке запуска. На исходной версии повторены те же 15 сбоев; тесты анимации и сохранений проходят.

Проверка на настоящем Android-устройстве и окончательное художественное согласование ещё не выполнены. После оценки этой Жужи можно переносить согласованные параметры на остальные модели.
