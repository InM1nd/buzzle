# Соты под существующую сетку — передача Гроку

Подготовлена только графика и отдельное превью. Основная игра, ссылки ART, логика улья и остальные ассеты не изменены.

| PNG | Назначение |
|---|---|
| comb.png | Заполненная медовая сота без числа |
| comb_empty.png | Пустая сота без встроенного плюса |
| comb_locked.png | Приглушённая сота без встроенного замка |
| ring.png | Прозрачная внутри рамка выделения |

Для каждого файла есть @2x и @3x: 200×173, 400×346, 600×519 px. Все имеют одинаковый холст и центральный якорь (0.5, 0.5), без внешней тени. Большие варианты *-master.png имеют 1000×866 px. Три состояния имеют побайтно одинаковую альфу внешнего контура, поэтому геометрия при переключении не меняется. Рамка имеет прозрачный центр и ограничена тем же внешним контуром.

## Что использовать при подключении

Форма flat-top: верхняя и нижняя стороны горизонтальны, вершины слева/справа. Повторяет сетку src/logic/hex.ts и размеры CombTile в src/screens/HiveScreen.tsx:

- ширина рисунка: `2 * s * 0.96`;
- высота рисунка: `sqrt(3) * s * 0.96`;
- положение: `left = x - width/2`, `top = y - height/2`;
- центр соты: `x = 1.5 * s * q`, `y = sqrt(3) * s * (r + q/2)`;
- не добавлять второй отступ 4% в PNG: уменьшение уже делает CombTile;
- число уровня и плюс остаются отдельными текстовыми слоями из игры;
- закрытое состояние: существующая непрозрачность 0.45 применяется к изображению один раз;
- рамка накладывается в той же прямоугольной области, без другого размера или смещения;
- для сохранения плотности пикселей можно использовать комплект PNG с суффиксами @2x/@3x.

В превью 19 слотов радиуса 2, исходные координаты и расстояния. Это графическая проверка, а не подключение в приложение. Оно не воспроизводит всю логику выбора/строительства и анимацию scale 1.08 выбранной соты. Бомба и прочие элементы головоломки не менялись; эта задача относится к сотам улья.

## Изготовление и проверка

Встроенный imagegen, transparent_background=true: новая заполненная сота на основе прежнего «Медового кристалла» и ориентации старого игрового PNG; три редактирования для пустой, закрытой и рамки. Полные промпты — manifest.json. Исходные генерации сохранены отдельно. Затем механическое кадрирование, регистрация в общем холсте, отсечение по регулярному шестиугольнику и общая альфа трёх состояний; материалы не перерисовывались кодом.

Проверены загрузка всех 12 PNG, отсутствие перекрытий соседних сот в обычном масштабе, единый центр, одинаковая альфа трёх состояний, контуры сетки, переключение выделения и ширины экрана 320/375/520 px. На ширинах браузера 320/375 px нет горизонтального переполнения, ошибок консоли нет. Художественные грани внутри состояний отличаются; это не геометрический сдвиг.
