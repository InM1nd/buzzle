# Награды — Медовый кристалл

13 октября 2026. Новые кандидаты для визуального утверждения:
- star.png — полученная золотая звезда.
- star-off.png — незаполненная звезда в приглушённых бежевых тонах.
- flame.png — огонёк.
- chest.png — закрытый сундук награды.

Все PNG 1254×1254, альфа 0–255. compare.png: крупные варианты, миниатюры 32/48/72 px и сравнение с ранее готовыми ресурсами.

Генерация: встроенный image_gen, transparent_background=true, отдельный вызов для каждой картинки. Полные промпты и исходные пути — manifest.json. Для стиля использованы новая банка мёда, нектар и деревянная коробка; старые игровые иконки — для сохранения смысла, цветов и узнаваемого силуэта. Незаполненная звезда сделана редактированием новой золотой с требованием сохранить форму.

Изображения просмотрены на общем листе и в миниатюрах. Основные силуэты читаются в 32 px, мелкая фаска замка сундука смягчается. Два состояния звезды визуально близки по форме, но генеративное редактирование не гарантирует точного совпадения всех пикселей: перед анимацией переключения нужно проверить наложение в интерфейсе.

Сундук отличается от шестигранных коробок: сохранены прямоугольный корпус, округлая крышка, две золотые полосы и замок. Это статичный закрытый рисунок; открытая крышка и внутренность ещё не подготовлены.

PNG скопированы без перерисовки. Коллаж собран только кадрированием, уменьшением и размещением готовых изображений. В рабочую игру не подключены, прежние ассеты не изменены. Файлы также сохранены в design/art/rewards-honey-crystal-v1 рабочей ветки; загрузка на GitHub на этом шаге не выполнялась.

Далее: специальные клетки головоломки и соты, общий просмотр в интерфейсе.
