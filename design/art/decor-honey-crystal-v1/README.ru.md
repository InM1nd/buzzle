# Декорации «Медовый кристалл», v1

13 октября 2026. Восемь новых статичных PNG для визуальной оценки. В основную игру не подключены.

## Файлы
barrel.png — бочка; lanterns.png — фонарики; fountain.png — фонтан; flags.png — флажки; mushroom.png — гриб; bench.png — скамейка; pinwheel.png — вертушка; gnome.png — садовый гном.
compare.png — полный комплект и миниатюры 32 / 48 / 72 px.
manifest.json — полный набор промптов и исходные пути генерации.

## Инструмент и референсы
Встроенный image_gen, отдельный вызов на каждый предмет, transparent_background=true.
Референсы: Жужа без короны для общего стиля, принятые коробки для света и граней, прежний лист предметов для узнаваемого дизайна.
Флажки и гном — новые дизайны: флажки на двух деревянных стойках, гном с красным колпаком и зелёной одеждой.
Первая версия флажков содержала ореол, попытка убрать его редактированием оказалась недостаточной. Финальный вариант сгенерирован заново по референсу коробок без ореола. Финальный промпт и источник указаны в manifest.json.
Исходные выбранные изображения скопированы без изменения рисунка и альфа-канала. Все PNG проверены, альфа содержит 0 и 255. Размеры различаются: от 1263×1245 до 1774×887, значения записаны в проверке; игровой масштаб нужно задавать отдельно.
Коллаж собран из выбранных PNG без перерисовки.

## Проверка и ограничения
Комплект просмотрен на белом фоне и в миниатюрах. Флажки горизонтальные и теряют мелкие детали при 32 px; их стоит показывать шире остальных декораций, а не втиснуть в одинаковый квадрат.
Фонарики содержат свет внутри плафонов, не внешний ореол.
Вертушка пока целое статичное изображение; лопасти и стойку нужно отделить перед вращением.
Вода фонтана пока встроена в рисунок; для анимации нужны отдельные водные слои и восстановленная неподвижная чаша.
Флаги пока без анимации ткани. Все декорации ожидают оценки владельца; рисунки ещё не подтверждают готовность игрового подключения.
