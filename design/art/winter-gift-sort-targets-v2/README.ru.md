# Сортировка подарков · четыре открытых мешка

17.11.2026. Новые: золотой sack_gold и голубой sack_blue. Красный/зелёный мешки скопированы из v1 без изменений; все четыре подарка — из winter-gift-sort-sprites-v2, также побайтно. Получился самодостаточный комплект для цветовой примерки.

PNG 512×512 RGBA и lossless WebP. preview.png — все мешки при 56/72/88 px на светлом/ночном фоне; all-pairs.png — четыре пары подарок/мешок. sources/ и generation.json — две новые генерации встроенного imagegen, полные промпты и референсы. checks.json — параметры новых экспортов.

Мешки пока цельные статические иллюстрации: для падения коробки внутрь нужны передний край и маска горлышка. Геометрия между цветами не заявлена как попиксельно идентичная. Новые PNG/WebP совпадают по видимым пикселям на двух фонах. assets/ и src/ не менялись, в игру не подключено.
