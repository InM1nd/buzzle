Privacy Policy

Buzzle is a small hobby game by Oleksandr Zabolotnyi. It has no ads, no purchases and no accounts. It collects only anonymous gameplay statistics, which you can turn off.

  • Your progress is stored on your device (Android app, web browser). Inside Telegram it is also saved in Telegram's CloudStorage for the bot @Buzzle_game_bot, so it follows you between your devices. We do not run our own servers and cannot see it.
  • Telegram passes the Mini App your public profile basics (such as your language). The game only uses your language to suggest one on the first launch; nothing is sent anywhere.
  • Anonymous statistics. To see whether players come back, the game sends a few gameplay events to PostHog (EU servers, eu.i.posthog.com): first launch, session start, daily puzzle completed (stars), streak day / break / freeze used, free-play round score and event points. Each event carries a random ID created on your device and stored in your save, the platform (Android, Telegram, web) and the app version. No name, Telegram ID, contacts, typed text or screen recordings are sent, and IP-based location lookup is disabled. Turn it off any time in Settings → Statistics; queued events are then deleted.
  • Updates (Android). When you check for updates (or once a day, if enabled), the app asks GitHub's public API for the latest release of github.com/InM1nd/buzzle and may download the APK from GitHub. GitHub sees a normal web request (your IP address, app user agent) under its own privacy statement.
  • Reminders are local notifications scheduled on your phone; no push service is used.
  • Save codes you export are plain text that stays wherever you put it.
  • Reset progress in Settings to delete your save; in Telegram this also clears the cloud copy.

Questions: open an issue at github.com/InM1nd/buzzle.

Політика конфіденційності

Buzzle — невелика гра-хобі Олександра Заболотного. У ній немає реклами, покупок і акаунтів. Вона збирає лише анонімну ігрову статистику, яку можна вимкнути.

  • Твій прогрес зберігається на пристрої (застосунок Android, браузер). У Telegram він також зберігається в CloudStorage Telegram для бота @Buzzle_game_bot, щоб переходити з тобою між пристроями. Власних серверів у нас немає, і ми його не бачимо.
  • Telegram передає Mini App базові дані профілю (наприклад, мову). Гра використовує мову лише для підказки під час першого запуску; нічого нікуди не надсилається.
  • Анонімна статистика. Щоб розуміти, чи повертаються гравці, гра надсилає кілька ігрових подій до PostHog (сервери в ЄС, eu.i.posthog.com): перший запуск, початок сесії, пройдена щоденна головоломка (зірки), день серії / обрив / використана заморозка, рахунок вільної гри та очки події. Кожна подія містить випадковий ID, створений на пристрої й збережений у твоєму збереженні, платформу (Android, Telegram, веб) і версію застосунку. Ім’я, Telegram ID, контакти, введений текст чи запис екрана не надсилаються, визначення місцезнаходження за IP вимкнено. Вимкнути можна будь-коли в Налаштуваннях → Статистика; події в черзі тоді видаляються.
  • Оновлення (Android). Коли ти перевіряєш оновлення (або раз на день, якщо це ввімкнено), застосунок звертається до публічного API GitHub по останній реліз github.com/InM1nd/buzzle і може завантажити APK з GitHub. GitHub бачить звичайний веб-запит (IP-адресу, user agent) відповідно до власної політики.
  • Нагадування — локальні сповіщення на телефоні; push-сервіси не використовуються.
  • Коди збереження, які ти експортуєш, — звичайний текст, що лишається там, куди ти його поклав.
  • Щоб видалити збереження, скинь прогрес у налаштуваннях; у Telegram це очищає й хмарну копію.

Питання: створи issue на github.com/InM1nd/buzzle.

Политика конфиденциальности

Buzzle — небольшая игра-хобби Александра Заболотного. В ней нет рекламы, покупок и аккаунтов. Она собирает только анонимную игровую статистику, которую можно отключить.

  • Ваш прогресс хранится на устройстве (приложение Android, браузер). В Telegram он также сохраняется в CloudStorage Telegram для бота @Buzzle_game_bot, чтобы переходить с вами между устройствами. Своих серверов у нас нет, и мы его не видим.
  • Telegram передаёт Mini App базовые данные профиля (например, язык). Игра использует язык только для подсказки при первом запуске; ничего никуда не отправляется.
  • Анонимная статистика. Чтобы понимать, возвращаются ли игроки, игра отправляет несколько игровых событий в PostHog (серверы в ЕС, eu.i.posthog.com): первый запуск, начало сессии, пройденная головоломка дня (звёзды), день серии / обрыв / использованная заморозка, счёт свободной игры и очки события. Каждое событие содержит случайный ID, созданный на устройстве и хранящийся в вашем сохранении, платформу (Android, Telegram, веб) и версию приложения. Имя, Telegram ID, контакты, введённый текст и запись экрана не отправляются, определение местоположения по IP отключено. Отключить можно в любой момент в Настройках → Статистика; события в очереди при этом удаляются.
  • Обновления (Android). Когда вы проверяете обновления (или раз в день, если это включено), приложение запрашивает у публичного API GitHub последний релиз github.com/InM1nd/buzzle и может скачать APK с GitHub. GitHub видит обычный веб-запрос (IP-адрес, user agent) в рамках своей политики.
  • Напоминания — локальные уведомления на телефоне; push-сервисы не используются.
  • Коды сохранения, которые вы экспортируете, — обычный текст, который остаётся там, куда вы его положили.
  • Чтобы удалить сохранение, сбросьте прогресс в настройках; в Telegram это очищает и облачную копию.

Вопросы: создайте issue на github.com/InM1nd/buzzle.
