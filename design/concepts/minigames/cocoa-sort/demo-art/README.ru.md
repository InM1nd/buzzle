# Какао-сорт — медовый кристалл и жидкость v2
Адрес: /cocoa-sort/demo-art/?revision=2. Предыдущая версия сохранена отдельно в demo-art-v1; демо без ассетов — demo.
Новые изображения (встроенный image_gen): art/mug-v2.png, jar-v2.png, cafe-background-v2.png; исходные PNG не изменены, WebP — уменьшенные копии. Референсы: Жужа и медовый зимний глиф. Крупные тёплые грани заменяют реалистичное стекло. Промпты в art/prompts-v2.json.
Рендер напитков: отдельный canvas, без текстуры жидкости. fluid.mjs обрезает многоугольник сосуда горизонтальными в мировом пространстве границами слоёв. Высота границы определяется площадью для заданного объёма, в том числе при наклоне. Во время переливания дробный объём непрерывно убывает и растёт, струя рисуется отдельным canvas, на принимающей поверхности рябь. Подъём/наклон/возврат синхронизированы с жидкостью.
Это стилизованная 2D-анимация, не гидродинамическая симуляция. Свободная поверхность и объём рассчитываются геометрически, брызги и волна — визуальные эффекты. Полная одноцветная кружка получает украшения и пар.
Анимация включается кнопкой; начальное положение учитывает системное reduced-motion. При выключении перелив мгновенный и рябь неподвижна.
Проверки: node test.mjs; node fluid.test.mjs. Сохранение объёма при углах 0, ±0.88 рад; промежуточные дробные объёмы; оба уровня пройдены через интерфейс, отмена победного хода, дополнительный сосуд, баночки, 360/390 px без горизонтального скролла. В браузере сняты четыре разных промежуточных кадра: исходный объём уменьшается, целевой растёт, их сумма постоянна. Файлы preview-v2.png, pouring-v2.png, mobile-360-v2.png.
Основная игра и игровые assets/src не менялись. Все версии сохранены в библиотеке.
