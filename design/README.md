## Реализация в RN (без reanimated/Skia)
- **1 Сказочный** — кривые контуры и акварель только картинками: PNG-гексы (5 цветов × обычный/выбран), рамки карточек (9-patch через capInsets), иконки, тайл текстуры бумаги. Шрифты Pangolin/Balsamiq Sans/Caveat (~0.3 МБ). Пунктир цепочки — View-точки.
- **2 Минимализм** — проще всего: плоские View/одна PNG-маска гекса с tintColor, значки — View-фигуры или крошечные PNG. Шрифты Inter Tight + Unbounded (только логотип можно PNG). Почти без новых ассетов.
- **3 Ночной сад** — свечение = PNG-спрайты (гексы с glow, ореолы, светлячки, цветы); светлячки — Animated opacity/translate. Стекло — полупрозрачные View (expo-blur по желанию). Фон-градиент — PNG или expo-linear-gradient. Линия цепочки — повёрнутые View + glow-PNG.
- **4 Карамель** — гексы-самоцветы PNG (как сейчас в Бзз), кнопки — PNG/9-patch или слоёные View; логотип с обводкой — PNG; обводка цифр — стек textShadow. Небо/лучи/холмы — PNG-фон.
