# Зимний шарф · три четверти и профиль

scarf-*.png / .webp — отдельные прозрачные спрайты, созданы встроенным imagegen. Промпты и референсы в generation.json, исходники в sources/. scarf-fitted-*.png — слои посадки на исходной Жуже с отсечением под ближним крылом. layout.json задаёт координаты. fitting-* — шарф отдельно, outfit-* — вместе с шапкой. На preview.png анфас взят из v1 без изменений. В игру не подключено.
