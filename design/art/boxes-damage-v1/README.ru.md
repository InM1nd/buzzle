# Коробки: повреждения и открытый сундук

По два промежуточных состояния для каждой из четырёх коробок, под существующие три нажатия на экране открытия. Третье нажатие завершает открытие — отдельную третью закрытую стадию не рисуем. Открытый сундук — отдельное состояние награды.

Инструмент: image_gen.imagegen; прозрачный фон; по одному исходному ассету в качестве референса для каждого состояния. Все промпты сохранены в manifest.json. Исходные закрытые коробки и сундук не изменены.

Новые коробки механически вписаны в исходный alpha-контур по масштабу, нижней границе и центру; оригиналы генерации сохранены как -raw.png. Незначительный дрейф граней и контура возможен: это кандидаты для проверки в переключении, а не точные попиксельные копии. Сундук с открытой крышкой имеет другой силуэт и требует общей опоры по нижней части при интеграции.

index.html позволяет переключать стадии. В основную игру и логику выдачи наград изменения не внесены.
